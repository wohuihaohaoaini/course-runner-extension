# 课程流程助手（Chrome 扩展）

超星学习通（`*.chaoxing.com`）课程页的悬浮窗助手：按任务点顺序播放视频、切换小节，可选用 AI（DeepSeek）处理视频弹题和章节测验。

## 适用范围

- **网站**：仅超星学习通 `https://*.chaoxing.com/*` 的课程学习页（`mycourse/studentstudy` 等），从课程目录进入。
- **浏览器**：Chrome 111+ 或 Edge 等 Chromium 内核浏览器，开发者模式加载。
- **任务点**：视频 / 音频（正常倍速播放）、文档（滚动到底）、章节测验（AI 填写，可选自动提交）。其他类型任务点记入待办后跳过。
- **视频弹题**：AI 作答（单选、多选、判断，含加密字体 / 图片题截图识别）；无需 AI 的单选顺序试答（2–4 项单选）；手动作答。
- **不处理**：验证码、人脸识别（始终等待人工）；不倍速、不拖进度、不修改平台完成标记；课程标签页需保持在前台。

## 安装

1. 从 [Releases](../../releases) 下载 `course-runner-extension-x.y.z.zip` 并解压到固定文件夹。
2. 打开 `chrome://extensions`，开启开发者模式，点“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
3. 打开课程学习页，在悬浮窗点击“开始”。

详细用法见 [安装与使用说明.txt](安装与使用说明.txt)。

## AI 说明

AI 功能需要自己的 DeepSeek API 密钥，只保存在本地扩展存储；开启后题目及必要截图会发送到 DeepSeek。AI 答案不保证正确。
