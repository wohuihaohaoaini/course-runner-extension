## 已复现的问题

### 1. [P1] 延迟状态写入可以撤销用户的暂停

位置：[content/runner.js:18](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/content/runner.js:18)，关联 [content/main.js:55](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/content/main.js:55)。

`saveTask()` 先读取整个任务，再把旧任务与更新字段合并后整份写回。它和 `pauseTask()` 没有共用串行写队列，也没有运行版本／状态的条件更新。如果一次状态读取已经取得 `running` 快照，但响应或后续写入晚于暂停，旧快照里的 `state: running` 就会覆盖用户刚保存的 `paused`。

本次用受控异步时序调用实际 `saveTask()` 与 `pauseTask()`，结果依次为：暂停后 `paused` → 延迟状态写回后 `running` → 原有答题流程继续提交 1 次。复现未修改这两个函数；只控制存储读取响应交回的时机。这证明并发保护存在缺口，实际浏览器中的自然触发频率尚未测量。

影响：暂停按钮无法在并发写入边界可靠终止自动操作；防旧答案的检查也会被恢复为 `running` 的状态误导。

修复方向：将任务状态写入集中到后台并按标签页串行处理，普通进度更新不能恢复 `state`，同时核对预期 `runId`／版本。用户暂停需要作为该队列中的独立状态操作，后续旧进度写入应被拒绝。增加“暂停与状态更新同时发生，之后不得填写、提交或换节”的回归用例。

### 2. [P1] 前台截图可以接受其他已授权标签页的画面

位置：[background-ai.js:240](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/background-ai.js:240)，后续裁切见 [content/quiz.js:308](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/content/quiz.js:308)，AI 请求入口见 [content/ai-flow.js:165](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/content/ai-flow.js:165)。

普通截图使用 `captureVisibleTab(windowId)`。该 API 截取指定窗口当时选中的标签页；它没有目标 `tabId` 参数。[Chrome 官方说明](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab)。

实现会先判断课程页为选中状态，隐藏面板并等待 120 毫秒，然后截图，最后再次确认课程页仍为选中状态。只比较两端状态，无法发现中间“切到另一标签页，截完再切回”的情况。

本次在独立 Chromium 配置中运行未修改的 `captureTab()`，保留原生浏览器截图 API，只在 API 调用边界安排可重复的切换时序。课程页与另一合成网页都先通过工具栏操作取得 `activeTab` 授权。实际被截取的页面为 `https://private-audit.invalid/document`，课程页在截图结果返回前重新选中，错误图片仍被函数接受。该合成域名的请求全部由测试拦截，没有访问真实私人页面。

证据：`acceptedOtherTabImage: true`，`courseActiveAfterCapture: true`，且 `capturedUrl` 是上述另一网页。[机器可读结果](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/验证/审查-2026-10-28/capture-race-result.json)与[被接受的合成画面](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/验证/审查-2026-10-28/accepted-other-tab.png)。

影响：开启 AI 截图答题时，其他网页的一部分画面可能被按题目坐标裁切并发给 AI。已确认的是“错误图片被接受”；后续外发风险由代码路径推导，本次复现禁止网络请求，实际外发次数为 0。普通截图还要求另一标签页也已取得授权；未满足此前提时，浏览器可能直接拒绝截图。

修复方向：截图期间记录标签页激活／导航的变化序号，只要发生过切换就丢弃结果，不能仅比较最终选中状态；在用户已允许后台截图的情况下使用绑定目标标签页的截图路径。补充“切走再切回”用例，验证错误画面不会进入裁切和 AI 请求。

### 3. [P2] 题库未命中后手动答对，插件仍停在未命中状态

位置：[content/ai-flow.js:264](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/content/ai-flow.js:264)。

`maybeVideo()` 对 `bank-miss` 状态只比较设置版本。版本没有改变就提前返回 `true`，没有先处理平台已经返回 `correct`／`continue` 的情况，阻止运行器进入原有“点击继续学习”流程。

复现：启用题库、关闭 AI → 当前视频题未命中 → 用户手动作答正确、平台出现“继续学习” → 连续轮询仍是 `bank-miss`，自动点击继续次数为 0。用户自行点击平台继续按钮可以绕过；否则仍显示旧的未命中提示，可能继续等到统一超时。

修复方向：`bank-miss` 只在题目仍待作答时阻止新的匹配请求；收到正确／继续反馈时交还正常结果处理流程，保留防重复提交保护。

### 4. [P2] 超时检查会把平台已完成的任务重新记入待办

位置：[content/stuck.js:35](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/content/stuck.js:35)，关联 [content/runner.js:763](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/content/runner.js:763)。

`StuckGuard.check()` 在等待到期后直接执行跳过，没有先确认本轮快照里的当前任务是否已经完成。运行器在等待阶段的正常完成处理之前调用它。

复现：任务正等待章节测验，截止时间已到，但这一轮已读到平台 `finished: true`；插件仍为该任务新增“等待 3 分钟仍未解决”的待办。其结果与刚读到的平台状态相反。

修复方向：超时处理前优先核对当前任务完成标记、弹题关闭／播放恢复等解除等待条件；已经完成或等待原因已解除时先走正常恢复流程，再判断是否需要记待办。

## 安全边界与加固项

**密钥隔离需要加强。** `apiKey` 与任务状态、题库等共同存入 `chrome.storage.local`；代码没有设置存储访问级别。Chrome 默认允许扩展内容脚本访问这个存储区域，普通网页 JavaScript 则不能直接取得该扩展 API。[Chrome 存储说明](https://developer.chrome.com/docs/extensions/reference/api/storage#storage_areas)。当前设计扩大了密钥在扩展内部的可见范围；本次没有证据证明普通课程页面已经能窃取密钥。建议将密钥放在仅受信任扩展上下文能访问的存储边界内，弹窗只查询“是否已保存”，内容脚本只读公开运行设置。

**管理消息没有区分扩展管理页与课程内容脚本。** [background.js:207](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/background.js:207) 对题库管理操作统一转发；[background-ai.js:541](/Users/wohuiaini/Documents/project/学习通插件/course-runner-extension/background-ai.js:541) 的完整设置更新也没有按 `sender.url` 区分调用方。建议将题库列表／导入／编辑／删除和完整密钥设置限制给实际扩展管理页；课程脚本只保留必要的开关、查题和运行命令，并继续校验运行上下文。这属于扩展内部权限隔离加固，本次没有发现把这些管理接口直接暴露给普通网页的消息桥。[Chrome 对内容脚本及消息边界的安全建议](https://developer.chrome.com/docs/extensions/develop/security-privacy/stay-secure#use-content-scripts-carefully)。

**已核对的现有保护：**

- 题库导入有题型、字段长度、答案范围、重复选项、题数与容量限制；冲突和无效导入不覆盖已有题库。
- 题库管理页使用 `textContent` 创建动态内容；填空写入先转义 HTML。未发现导入 JSON 后把其中内容当作脚本执行的路径。
- 正常纯题库路径不调用 AI；AI 网络请求使用固定 HTTPS 端点。未发现任意 URL 代理或额外固定上传端点。
- 截图在题目区域裁切，调试截图设有范围、时间和释放逻辑；前台截图仍有问题 2 的来源校验缺口。
- 诊断日志有字段白名单，不直接保存题干、答案、截图和密钥。任务待办仍包含本地课程名称及回访链接，题库本身也保存在本机。
- Manifest V3 未声明外部消息监听、网页可访问脚本资源或放宽到 `unsafe-eval` 的扩展 CSP；页面主环境点击桥没有暴露存储或后台管理接口。
- 当前申请 9 项权限，含 `debugger`、`scripting`、`tabs`；`debugger` 在安装时声明，使用逻辑受后台截图开关约束。题库功能独立使用时仍随整个扩展持有这些权限。
